# 饭团音乐 · Music Fan
[English README](../../README-EN.md)
饭团音乐是一款 Android 音乐播放器，主要面向本地音乐以及个人自托管音乐库。

它希望把分散在手机、个人服务器以及网络存储中的音乐，集中到一个统一的播放体验中。除了本地音乐外，目前支持 Navidrome、WebDAV 等音乐来源，并提供统一的音乐库、播放队列、歌词和离线播放功能。

## 功能

### 音乐库

- 本地音乐扫描与管理
- 支持个人音乐服务器
- 支持 Navidrome
- 支持 WebDAV
- 不依赖第三方在线音乐平台提供音乐资源
- 支持多个音乐来源

### 播放

- 播放队列
- 随机播放
- 单曲循环
- 列表循环
- 歌词显示
- 离线播放
- 后台播放
- 锁屏及系统媒体控制

### 界面

- 基于 Jetpack Compose 构建
- 针对手机和平板进行适配
- 支持不同屏幕尺寸
- 以 Material 3 为基础，同时尝试融入其他平台的设计思路
- 播放页面、音乐库、歌曲列表等界面均为独立设计

## 音乐来源

饭团音乐主要面向自己的音乐收藏。

本地音乐可以直接从设备上的音乐文件夹建立音乐库；如果音乐存储在个人服务器上，也可以通过 Navidrome、WebDAV 等方式访问。

项目不会提供或内置未经授权的商业音乐资源，也不会以第三方在线音乐平台作为主要音乐来源。

## 开发状态

饭团音乐目前仍处于开发阶段。

项目会根据实际使用过程中的问题持续进行修改，包括：

- 播放体验
- 音乐库管理
- 网络音乐来源
- 歌词
- 播放队列
- 手机和平板适配
- 动画与交互细节
- 性能与稳定性

部分功能可能仍然存在问题。如果遇到异常，可以通过 GitHub Issues 反馈。

## 关于项目

饭团音乐是一个个人开发的 Android 音乐播放器项目。

这个项目并不是为了替代某个特定的商业音乐播放器，而是为了做一个更符合自己使用习惯的音乐播放器。

项目比较重视本地音乐和自托管音乐库，也比较重视播放过程中的交互细节以及不同设备上的使用体验。
